# Applies primary or secondary approach to ties

Applies primary or secondary approach to ties

## Usage

``` r
ties(d, delta, method = c("primary", "secondary"))
```

## Arguments

- d:

  observed dissimilarities

- delta:

  given dissimilarities to match (order)

- method:

  either `primary` or `secondary` approach to ties

## Value

a vector of ordered values
